FreeCodeCamp challenge: Tribute Page
Author: Marianne Kobierski
Date: 30 Dec 2017
Description: This tribute page was built to fulfill the following user stories:

  • User Story 1 – I can view a tribute page with an image and text.
  • User Story 2 – I can click on a link that will take me to an external website.

The page was built in CodePen using HTML and CSS. The Bootstrap library was used to make the image responsive.
