[PLC] PLC Programming

May 16, 2019

What do you get if you combine low level programming, controls, and mechanical components? PLC programming of course!

I’ve completed two PLC courses on Udemy so far. The first is a beginner course: PLC Programming from Scratch (PLC I), by Paul Lynn. This one introduced the Allen Bradley RSLogix programming environment, and the basic tools and concepts.

The second was an intermediate course: Practical PLC Programming (PLC II). This one had a series of project specifications to be worked through. I uploaded my projects to GitHub as I went (with videos and some ReadMe commentary); feel free to check them out here:

MKobie/PLC-Programming GitHub repository

I’m looking forward to the day I can put this new skill to work in a real-world environment.
